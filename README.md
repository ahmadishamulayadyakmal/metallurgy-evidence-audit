# Cross-case evidence audit and public release (C12)

> Workspace folder: `e12-release-paper-portfolio` · Suggested GitHub repository: `metallurgy-portfolio-site`
> Epic: E12 · Weeks: W48–W51 · Evidence level: **A**
> Master specification: [`CASES.md`](https://github.com/ahmadishamulayadyakmal/metallurgy-project/blob/main/CASES.md) §4 · Download the papers: [`JOURNALS.md`](https://github.com/ahmadishamulayadyakmal/metallurgy-project/blob/main/JOURNALS.md)

## Industrial problem

Across eleven cases, an engineering organisation must be able to answer: which published numbers did we actually reproduce, which are external literature, and which claims are unsafe to put in a decision memo?

**Why it happens.** Aggregated portfolios blur 'we measured' and 'the paper reports' — exactly the reproducibility failure studied in C01.

## Data (no plant data)

Open data only: the outputs, checksums and provenance manifests of C01–C11, all generated locally from open data. Evidence level A.

> The author cannot supply factory data. This project uses **only open datasets and
> credible peer-reviewed journals**. If this is a B-level case, the case report
> must contain the exact disclaimer from `CASES.md` §1 and must **never** claim
> plant validation.

## Tool chain

BibTeX / `CITATION.cff`, `JOURNALS.md` download list, V&V audit against R31, figure regeneration scripts, Zenodo `v1.0.0` DOI, static portfolio site / dashboard, preprint.

## Journal references

- **R31** — the audit standard for verification, validation and uncertainty claims.
- **R01** — the ICME narrative tying the cases together.
- **R05** — ML pipeline reporting checklist.
- **R07** — citation of data tooling.
- **Y2R12** — error-modality warning used as the worked audit example.

Each reference above is listed with its DOI or stable URL, access status and
manual download route in [`JOURNALS.md`](https://github.com/ahmadishamulayadyakmal/metallurgy-project/blob/main/JOURNALS.md) §4, and in the shared
BibTeX library `papers/references.bib`. Do not cite a paper you have not been
able to obtain; if it is inaccessible, record that in `JOURNALS.md` §8.

## Deliverables

`v1.0.0` release; Zenodo DOI; preprint / technical article; 12 paper-format case READMEs; dashboard regenerated by script; completed `JOURNALS.md` checklist; table of reproduced vs external numbers for all cases.

## Validation & claims

Third-party clean-state reproduction; every A-level number traceable to a dataset checksum; every B-level number traceable to a DOI.

## Limitations

Publication layer only; the physics lives in E01–E11. No publisher PDFs are committed.
