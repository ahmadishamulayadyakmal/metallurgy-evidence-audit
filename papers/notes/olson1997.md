# Reading note — Olson (1997), R01

**Paper:** G. B. Olson, *Computational Design of Hierarchically Structured
Materials*, Science 277(5330), 1237–1242, DOI
`10.1126/science.277.5330.1237`.

## Claim

Materials design should connect processing, structure, properties, and
performance through computational models rather than treating each scale
independently.

## What this portfolio takes

- The **P–S–P–P chain** (Processing → Structure → Properties → Performance) is
  the narrative backbone: CFD/heat transfer for processing, phase field for
  structure, ML for properties, and application targets for performance.
- A justification for the end-to-end ICME sprint W47–W48: the value is in the
  coupling, not in any single model.
